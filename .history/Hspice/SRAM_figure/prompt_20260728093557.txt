# SRAM 电位标注：连接逻辑与寻找方法

## 目标

从 `sram.txt` 取得 6T SRAM 的电气网络定义，并在
`FLOW/test/INPUT_MODEL/test_gds.txt` 中只给以下四类候选层的图形写入
电位标签。**标签的权威来源是 `sram.txt` 的 `(R){...}` 端点名和每条 `R_...`
关系；不得先按常识把端点替换为 Q/QB/VDD 等简写后再标注。**

1. 所有存在 M0、M1、M2…中编号最大的 M 金属层（最高前侧金属层）；
2. 所有存在 BM0、BM1、BM2…中物理 z 坐标最低的 BM 金属层（最低背侧金属层）；
3. MD 层；
4. BMD 层。

层号必须优先从 layer-rule 文件读取。本工程标准映射为：`MD=16`、
`BMD=51`、`M0=19`、`M1=21`、`M2=23`、`BM0=53`。相邻金属之间的通孔
为 `V0=18`、`V1=20`、`V2=22`…；`BV0=52` 连接 BMD 与 BM0。

“存在”定义为该层图形的并集面积大于零。最高 M 层取存在的最大 i；例如
M2 无面积而 M1 有面积，则选 M1。最低 BM 层应由 layer-rule 的 z 范围判断，
取 `end_z2` 更小的已存在 BM 层；没有 z 信息时，按 BM 编号增大表示更靠背面
（更低）处理。当前 `test_gds.txt` 中只有 M0 和 BM0，所以候选层分别是
M0(19)、BM0(53)、MD(16)、BMD(51)。

## R{} 电位关系（这是标注的唯一电气依据）

`(R){...}` 内列出的是不可再拆分的端点原子，例如 `PG1_G`、`PG1_SD2_Q`；
下划线是端点名称的一部分，不能把 `PG1_G` 错切成 `PG1` 和 `G`。每一条 `R_...`
把其中列出的端点原子做一次电气合并。解析时必须以 `(R){...}` 的端点清单作词典
并采用最长匹配，例如：

```text
R_WL_PG1_G                 => [WL, PG1_G]
R_PG1_SD2_Q_PU1_SD2_Q_...  => [PG1_SD2_Q, PU1_SD2_Q, ...]
```

把全部 R 项执行并查集（union-find）后，可得到下列**辅助网络别名**：

```text
WL  = PG1_G = PG2_G
BL  = PG1_SD1
BLB = PG2_SD2
VDD = PU1_SD1 = PU2_SD1
VSS = PD1_SD2 = PD2_SD2

Q   = PG1_SD2_Q = PU1_SD2_Q = PD1_SD1_Q = PU2_G_Q = PD2_G_Q
QB  = PG2_SD1_QB = PU2_SD2_QB = PD2_SD1_QB = PU1_G_QB = PD1_G_QB
```

这些别名只用于检查电路是否自洽，不得替代 R 端点名写回标注。对应的器件链可作为
交叉核验：

```text
BL  -- PG1(gate=WL) -- Q  -- PD1(gate=QB) -- VSS
VDD -- PU1(gate=QB) -- Q

VSS -- PD2(gate=Q)  -- QB -- PG2(gate=WL) -- BLB
VDD -- PU2(gate=Q)  -- QB
```

因此 Q/QB 是交叉耦合存储节点：Q 必须接 PG1、PD1、PU1 的输出端并接到
PD2/PU2 的 gate；QB 对称地必须接 PG2、PD2、PU2 的输出端并接到 PD1/PU1
的 gate。它只用于验证 R{} 与几何的对应关系；绝不可因为二维投影相交而把 VDD
与 VSS，或 Q 与 QB，直接短接。

## 当前 `test_gds.txt` 的器件排列：双层 CFET，而不是单层串联

该版图沿 x 方向以 42 nm 为一个 gate/SD pitch 排列。四条 Gate（layer 7）
的中心依次为 `x=0.021, 0.063, 0.105, 0.147 um`；相邻的 S/D 落点依次为
`x≈0, 0.042, 0.084, 0.126, 0.168 um`。因此它不是把六只管串在同一个
平面上的结构，而是两个 z-tier 在相同 x-y 投影下堆叠的 6T CFET：

```text
上层（top tier，NFET；由 MD=16 向前侧 M0/M1…引出；一条连续 active 链）
BL -- PG1(gate=WL, x=0.021) -- storage-A -- PD1(gate=QB, x=0.063) -- top-center
   -- PD2(gate=Q, x=0.105) -- storage-B -- PG2(gate=WL, x=0.147) -- BLB

下层（bottom tier，PFET；由 BMD=51、BV0=52 向背侧 BM0 引出）
                storage-A -- PU1(gate=QB, x=0.063) -- bottom-center
              bottom-center -- PU2(gate=Q, x=0.105) -- storage-B
```

按每一根物理 gate 的功能，坐标与器件的对应关系为（最后一列只列出 R{} 端点，
不是要写入的 Q/QB 简写）：

| Gate x 中心 (um) | 上层 NFET | 下层 PFET | R{} gate 端点 |
| --- | --- | --- | --- |
| 0.021 | PG1：BL ↔ storage-A | 无功能 PFET | `PG1_G` |
| 0.063 | PD1：storage-A ↔ top-center | PU1：storage-A ↔ bottom-center | `PD1_G_QB`、`PU1_G_QB` |
| 0.105 | PD2：top-center ↔ storage-B | PU2：bottom-center ↔ storage-B | `PD2_G_Q`、`PU2_G_Q` |
| 0.147 | PG2：storage-B ↔ BLB | 无功能 PFET | `PG2_G` |

上层两行文字只是为适应页面宽度的换行，物理上是上面的**一条连续横向 active
链**，中心 S/D `VSS` 同时为 PD1 和 PD2 所共享。两个外侧 gate（PG1、PG2）
下方没有功能 PFET；这是 6T CFET 中“4 个上层 NFET + 2 个下层 PFET”的原因。
中间两个 gate 位置在上下层分别对应 `PD1_G_QB/PU1_G_QB` 与
`PD2_G_Q/PU2_G_Q`。它们可以是共栅或 split gate 后再由金属接通；输出标签仍须
保留上述 R{} 原始端点名，不能改写为 Q 或 QB。

R{} 对该排列给出的端点证据必须逐字保留：`PG1_SD1=BL`、`PG2_SD2=BLB`、
`PU1_SD1=PU2_SD1=VDD`、`PD1_SD2=PD2_SD2=VSS`；storage-A 则由
`PG1_SD2_Q`、`PU1_SD2_Q`、`PD1_SD1_Q` 等 R 端点表示，storage-B 由
`PG2_SD1_QB`、`PU2_SD2_QB`、`PD2_SD1_QB` 等 R 端点表示。PD2 的两个端点
现已清晰区分：`PD2_SD2` 属于 VSS 的 R 关系，`PD2_SD1_QB` 属于另一条 R 关系；
应按该 R{} 关系分别定位和
标注，不能因其相邻或投影重叠而合并。

最重要的投影冲突在中心 S/D 落点 `x≈0.084 um`：上层 top-center 由 R{} 指向
VSS，而下层 bottom-center 由 R{} 指向 VDD。两者可以有重叠的 x-y 坐标，却位于
不同 z 层，必须分别经 MD 与 BMD 引出；只有存在明确的跨层接触才可连接，而本
电路绝不允许把这里的 VSS 与 VDD 合并。storage-A/B 仅在其接触到的 R 端点属于
同一 R 分量时，才可通过明确的 MD/BMD/MRW/VMM/BVD 路径作垂直合并。

由此产生本例的优先标注锚点：上层 MD 应识别 `PG1_SD1`、`PG1_G`、
`PG1_SD2_Q`、`PD1_SD1_Q`、`PD1_G_QB`、`PD1_SD2`、`PD2_SD2`、
`PD2_G_Q`、`PD2_SD1_QB`、`PG2_G`、`PG2_SD2` 等实际命中的 R 原子；下层
BMD 同理使用 `PU1_*`、`PU2_*` 原子。若同坐标命中多个同网原子，用 `_` 串接。
BM0 的 `VDD` 轨道只能向下层 BMD 的 `PU1_SD1/PU2_SD1` 接触传播；它不是上层
中心 VSS 的证据。

## 几何连通图的建立方法

1. 读取每个矩形的 `(x1,y1,x2,y2,layer,label)`，统一端点顺序。先由 R{} 建立
   端点原子与 R 连通分量；已有标签仅可作为定位某个 R 端点/分量的线索，不能覆盖
   或改写 R{}。同一几何分量若命中属于不同 R 分量的端点，视为短路/输入错误。
2. 在同一导电层上，仅把有面积重叠或边界接触（允许数值容差 epsilon）的矩形
   连边；同层但间隔大于 epsilon 的矩形不连通。
3. 跨层只能经**显式且合法的接触层**连边，并要求接触图形与上下两端的金属
   投影重叠。前侧主链为 `MD/MRW -> V0 -> M0 -> V1 -> M1 -> V2 -> M2 ...`；
   背侧主链为 `BMD -> BV0 -> BM0`。MD 接触上层 NFET 的 S/D，BMD 接触下层
   PFET 的 S/D；gate 接触只可把对应 gate 接入 R{} 指定的 gate 端点关系。
4. MD 与 BMD 不能仅因 x-y 投影重叠而相连。只有 MRW、BVD、VMM 或规则中
   明确声明的垂直接触同时覆盖两端时，才允许跨前/后侧合并。Q 与 QB 各自的
   主垂直合并点应独立；VDD/VSS 也必须保持独立。
5. 对几何连通图求 connected components，再把每个分量所接触的 R 端点与 R 并查集
   对照。仅当全部命中的端点都属于同一个 R 分量时才可标注；端点不全、属于不同
   R 分量，或无法由几何证明接触时，保持 `None` 并报告原因。

### 同位置端点的下划线合并规则（标注规则）

若两个或多个器件端点对应到**同一个物理位置**（例如同一 MD/BMD 接触落点），
标注值就是这些端点名以 `_` 串接；这是坐标标签，不是 Q/QB 等网络别名。例如
端点 `a_SD1` 与 `b_SD2` 位于同一 MD 时，写作：

```text
a_SD1_b_SD2
```

对于本输入，若同一位置经几何核验对应 `PG1_SD2_Q` 与 `PD1_SD1_Q`，则保留
R{} 中的完整端点文字并写作：

```text
PG1_SD2_Q_PD1_SD1_Q
```

单一端点则保持其原始 R 名称（如 `PG1_G`、`PU1_SD1`）；`VDD`、`VSS`、`BL`、
`BLB`、`WL` 本身也是 R 端点，故可原样写入。R{} 用于验证被拼接的端点确实应
通过该接触连通；几何位置用于决定是否需要拼接。不能把“同一 R 网络但位于不同
坐标”的端点拼进同一个标签，也不能仅因 x-y 投影重叠、没有 MD/BMD/via 接触就
拼接。

## 标注步骤与输出规则

1. 先统计各 M/BM 层的并集面积，选出目标 M 与目标 BM 层；不要在非目标 M/BM
   层新增标签。
2. 建立完整连通图后，再筛选目标层：`目标最高 M`、`目标最低 BM`、`MD`、`BMD`。
   对每个目标矩形填入该坐标命中的 R 端点名；同一 MD/BMD/via 落点的多个端点
   以 `_` 按 R{} 清单中的顺序串接。不要把它们缩写为 Q/QB，也不要因为仅属于
   同一个 R 网络、但坐标不同而拼接。
3. 一个网络在同一目标层可有多个断开的图形，均应标为该网络；不能只按坐标
   最近或按图形面积最大来猜测。
4. 不改动非目标层已有标签；不为不确定图形补标签；输出前复查每个标签是否与
   上述 SRAM 器件链一致，并保留 `None` 表示无从证明的网络。

## 本例的快速核对

当前输入已能在 M0 上看到 `WL`、`BL`、`BLB`、`VSS`，在 BM0 上看到 `VDD`。
这些只能作为种子，不可据此把邻近但未通过 V0/V1/V2/BV0/MRW 等显式接触连接的
图形强行染成同一电位。应由完整连通图继续向 MD、BMD 与 M0/BM0 传播标签。
